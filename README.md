# recuperate-skill

A Claude Code skill that builds a cached, comprehensive understanding of a project's raw source code from its git repo — internal file dependencies, external libraries, a full-text search index, public API surface, per-line logic, and domain ecosystem context — as the foundation for planning a roadmap or a large-scale refactor.

See `SKILL.md` for the workflow and `agents/` for the six crawlers that build each part of the cache.
